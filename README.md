# Robotic Arm

Robotic Arm is a small NeoForge 1.21.1 technology mod. It adds an energy-powered
arm with mining, crafting and item-transfer tasks, a Digital Haven mission
villager, decorative machine blocks, and core resources.

Use Java 21 and run `./gradlew build` to build, or `./gradlew runClient` to
launch the development client. Find the villager and complete its three
missions to receive the arm blueprint.
